# Яндекс Метрика: счётчик и цели vibememory.ru

Руководство «как подключить» по шагам
Решение и границы — запись «Яндекс Метрика с согласием» в `docs/decisions.md`
Политика конфиденциальности — `app.vibememory.ru/policy`, раздел 3 (исходник `VibeMemory/cabinet/src/pages/policy.ru.md`)

## Текущее состояние

Счётчик не заведён: номер в `src/config/site.ts` пуст, сайт ничего не грузит и плашку не показывает

## 1. Завести счётчик

1. В Метрике создать счётчик на домен vibememory.ru
2. Включить Вебвизор
3. **«Записывать все поля» оставить выключенным**
4. Скопировать номер счётчика (только цифры)

## 2. Включить на сайте

1. В `src/config/site.ts` вписать номер в `metrika.counterId`, например `'12345678'`
2. `bun run check`, затем выкладка командой `./deploy.sh`
3. Пустая строка выключает Метрику целиком: нет плашки, нет скрипта, нет запросов к `mc.yandex.ru`

Метрика грузится, только когда есть номер **и** посетитель нажал «Согласен»
Решение хранится в cookie `vibememory_cookies` на год; «Настройки cookie» в подвале спрашивают снова
Отказ после согласия стирает cookie `_ym…` и перезагружает страницу без счётчика

## 3. Завести цели

В Метрике: Настройки → Цели → Добавить цель → тип **«JavaScript-событие»**
Идентификатор — из таблицы, символ в символ

| Идентификатор        | Название в Метрике          | Когда срабатывает                                                  |
| -------------------- | --------------------------- | ------------------------------------------------------------------ |
| `start_click`        | Переход к старту            | Нажата кнопка «Начать» в шапке, герое или финальном блоке          |
| `start_free`         | Тариф: бесплатный           | Нажата кнопка бесплатного тарифа в блоке цен                       |
| `start_paid`         | Тариф: платный              | Нажата кнопка платного тарифа в блоке цен                          |
| `signin_click`       | Переход ко входу            | Нажата ссылка «Войти» в шапке, герое, финале или подвале           |
| `download_click`     | Переход к скачиванию        | Нажата ссылка «Скачать» в подвале или в шаге «Как это работает»    |
| `agent_release_open` | Релизы агента открыты       | Нажата ссылка VibeIDE или VibeIDEA в первой строке героя           |
| `command_copy`       | Команда подключения скопирована | Нажата кнопка копирования команды `vibememory connect`         |
| `changelog_click`    | Запись журнала открыта      | Нажата карточка выпуска в блоке журнала на лендинге              |
| `changelog_more_click` | Архив журнала открыт      | Нажата кнопка «Ещё» в блоке журнала на лендинге                  |

Цель срабатывает, только если Метрика уже загружена: у посетителя без согласия целей нет
Новая цель: `data-goal="id"` на ссылке или кнопке, id — латиница, цифры и `_`, строка в таблицу; тест `tests/metrika.test.ts` не даст забыть

## 4. Что скрыто в Вебвизоре

Поля `input`, `textarea` и `contenteditable` получают класс `ym-disable-keys` до первой записи (на лендинге полей ввода нет)
Заголовки страниц отправляются: на лендинге они не личные
